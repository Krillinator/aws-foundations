# AWS Foundations

A practical collection of notes, examples and visual explanations created while learning AWS.

This repository is an ongoing attempt to make AWS easier to understand.. not by memorizing services and terminology, but by understanding 
**what they do, why they exist, and how they fit together**.

> These are personal learning notes, not official AWS documentation.

---

## About

AWS is huge. 
It's easy to learn individual services without really understanding how they relate to each other.
The goal of this repository is to build that bigger picture gradually.

Concepts are explained with:

- simple explanations
- practical examples
- screenshots
- diagrams
- comparisons
- small mental models

The focus is always:
**What is it? → Why would I use it? → How does it fit into AWS?**
